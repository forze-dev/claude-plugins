# docs/brief/ — the client's text materials

The brief, specs, notes and answers from the client, as received (or as close
as possible: a PDF can stay a PDF). Task files cite these files as sources.

Unlike `temp/`, this folder is tracked by git — a source that disappears on a
fresh clone is no source. Heavy media (photos, video, archives) still go to
`temp/`. Never put credentials here.
